GRADES: Global Reach-Scale Discharge Estimates for SWOT

A model-derived river discharge product for global reach-level hydrology and river-network analysis.

Jul 20264 min readDataset note

Useful for reach-level context, with an important caveat.

GRADES provides daily discharge estimates for millions of vector river reaches. The official page now labels the original product as legacy and points users to GRADES-hydroDL for new work.

What it contains

The original GRADES product combines a land-surface model, river routing, calibration, and bias correction to estimate daily discharge for roughly 2.94 million reaches over 1980–2013. It is built around VIC, RAPID, MERIT-Hydro, MSWEP, and NCEP CFSR inputs.

This makes it useful as a global hydrological covariate, for reach screening, and for connecting river-network geometry with seasonal flow conditions. It is a modeled product, so it should not be presented as a direct gauge record.

Use the upgraded product for new work

The provider recommends GRADES-hydroDL for new analyses. It extends the period toward the present, uses updated MERIT-Basins hydrography, and maps streamflow to SWORD reaches to support comparisons with SWOT estimates.

For a paper or pipeline, record whether you used legacy GRADES or GRADES-hydroDL. The product name carries methodological and temporal information.
