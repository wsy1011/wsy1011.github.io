EarthEnv Topography: Elevation, Slope, and Terrain Context

A standardized global topographic layer collection built for environmental and spatial analysis.

Jul 20264 min readDataset note

Topography is more than elevation.

EarthEnv turns global elevation sources into a consistent family of terrain variables, making slope and ruggedness available alongside elevation at several spatial grains.

What it contains

The EarthEnv topography page provides elevation, slope, aspect, eastness, northness, roughness, terrain ruggedness, topographic position, curvature, and landform classes. The product is based on GMTED2010 and near-global SRTM data.

This is useful when a model needs terrain context rather than a single DEM value. For example, elevation can describe broad gradients while slope and ruggedness capture local constraints on runoff, access, or infrastructure.

A clean extraction workflow

Choose the spatial grain before downloading, keep the source layer and aggregation visible in your data dictionary, and use the same coordinate reference system and resampling rule across covariates. A slope value at 1 km is not interchangeable with a slope value at 100 km.

EarthEnv is a derived product. Cite the EarthEnv page and the underlying methodological paper when the terrain variables are part of a published analysis.
