River CO₂ Transfer Velocity: A Paper-Supplied Data Source

The gas-transfer and riverine CO₂ evasion inputs in the screenshot come through a cited paper and its supplementary materials, not a standalone portal.

Jul 20263 min readDataset note

This source needs citation-level tracking.

For this input, the paper's reference number is part of the data provenance. The correct workflow is to retrieve the referenced article and supplementary files, then record which table or variable was used.

The cited source

The source paper cites Liu et al., The importance of hydrology in routing terrestrial carbon to the atmosphere via global streams and rivers. Its supplementary material contains the supporting data and methods used for gas transfer velocity and riverine CO₂ evasion calculations.

This is different from a simple download page. The variable definition, spatial aggregation, and unit conversion need to be read together with the paper rather than inferred from a file name.

How to record it

In a data dictionary, save the paper DOI, supplementary-file URL, reference number, variable name, unit, spatial and temporal support, and any transformation applied before joining it to the vessel-emission analysis.

Do not label this input as a new independent dataset unless the authors provide a separate repository record. Here, the paper and supplement are the source.
